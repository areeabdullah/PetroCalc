Formulas & calculation method

Transparent educational model; not a certified implementation of the complete API MPMS 11.1 procedure.

1. Thermal expansion coefficient

α₆₀ = K₀ / (ρ₆₀*)² + K₁ / ρ₆₀* + K₂

α₆₀ is the coefficient of thermal expansion at 60°F. K constants depend on product family. This prototype uses density in kg/m³ with the displayed coefficient sets.

Candidate familyK₀K₁K₂
Gasoline group192.45710.24380
Fuel Oils group103.8720.27010
API guidance distinguishes virgin naphtha (Gasolines group) from heavy naphtha (Fuel Oils group). Mixed Naphtha must be classified using product characterization; density alone is not enough.

2. Temperature correction in this prototype

CTL ≈ exp[−α₆₀ × (T − Tᵦ)]
ρᵦ ≈ ρobs / CTL

T is observed temperature and Tᵦ is base temperature. This exponential form is an educational approximation, not the complete official API CTL algorithm.

3. Density and volume

ρ = m / V    and    V = m / ρ

At fixed mass, volume changes inversely with density.

4. Limitations

  • No official API iterative calculation.
  • No CPL pressure correction or combined CTPL.
  • No automatic identification of Mixed Naphtha class.
  • Not for custody transfer, fiscal measurement or operational control.
